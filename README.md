# برنامج حسابات فارس الأعور

مشروع Flutter أولي يعمل دون اتصال، بواجهة عربية حديثة.

## الوظائف المنفذة
- إضافة حسابات العملاء.
- تسجيل حركات «له / عليه» مع البيان والمبلغ والتاريخ.
- عرض رصيد كل حساب وإجمالي الأرصدة.
- عرض الحركات وحذف حركة.
- حفظ البيانات محلياً باستخدام SharedPreferences.

## مهم
هذا نموذج أولي وليس نسخة مطابقة وظيفياً لتطبيق «دفتر الحسابات»؛ لم يتم التحقق من كل وظائف التطبيق الأصلي. لا يحتوي حالياً على تقارير PDF أو نسخ احتياطي أو تسجيل دخول أو مزامنة. لا تستخدمه كسجل مالي إنتاجي قبل اختبار النسخ الاحتياطي وسلامة البيانات.

## البناء من الهاتف عبر GitHub
1. أنشئ مستودعاً جديداً على GitHub باسم `faris-accounts`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، بما فيها `.github/workflows/build-apk.yml`.
3. افتح تبويب Actions ثم Build Android APK ثم Run workflow (أو ادفع التغييرات إلى main).
4. بعد نجاح التنفيذ، افتح آخر تشغيل وحمّل `faris-accounts-apk` من Artifacts.
5. فك ضغط الملف ثم ثبّت `app-release.apk` على هاتف أندرويد.

ملاحظة: لم يتم اختبار بناء APK في هذه البيئة، لذا قد يتطلب المشروع إصلاحات طفيفة عند أول تشغيل لـ GitHub Actions.
